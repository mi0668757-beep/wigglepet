# WigglePet

![头顶饭碗的白猫桌宠：饭碗摇摇欲坠，眼睛会眨，勺子在抖](docs/demo.gif)

导入一张卡通图，整张图变成一只桌面宠物：构图不散开，只有选中的部分在原位动。趴着的角色会爬，歪着的纸箱快要掉下来，眼睛会眨。还能提醒你吃饭、喝水和看微信。

不需要显卡，基础功能也不需要 API Key。图片和设置保存在本机，只有你主动点「自动识别」时，图片才会上传给你配置的模型服务。

## 功能

- **导入图片：** 支持 PNG、WebP 和 JPG，透明背景或纯色背景都可以，纯色背景会自动抠掉。
- **整张图是一只桌宠：** 图里有多个对象时不会散开，构图保持原样，可以一起拖动。
- **选择会动的部分：** 点一下就能选中图里的猫、尾巴这类部分，让它们在原位做动作，其他部分不动。分割模型在本机运行。
- **按姿势配动作：** 趴着的可以爬，眼睛可以眨，歪着的东西可以摇摇欲坠。部分之间可以设跟随，纸箱晃时，坐在上面的猫也会跟着晃。
- **自动识别（可选）：** 看图模型判断画面主题和每个对象的姿势，自动抠图并配好动作和跟随关系，之后还能手动改。桌面上只留识别出的主体，背景和装饰会去掉。
- **单个角色会走动：** 只有一个角色时，自动找出两条腿走路；没有腿的按形状蹦跳、平移或摇摆。
- **桌面互动：** 透明置顶、点击跳起、拖动，大小可选。
- **点击穿透：** 只有鼠标压在图上才会拦截，空白处可以正常点到后面的窗口。
- **微信消息提醒（macOS，默认关闭）：** 来新消息时跳起来并显示未读数，点一下打开微信。
- **到点提醒（默认开启）：** 中午和傍晚提醒吃饭，饭后过一会儿和平时隔一段时间提醒喝水，晚上不打扰。

## 下载安装

到 [Releases](https://github.com/mi0668757-beep/wigglepet/releases) 下载安装包，不需要安装 Node.js。分割模型已经打包在里面，安装后可以离线使用；自动识别需要在窗口里填自己的 API Key。

安装包暂时没有开发者签名，第一次打开时系统会提示风险：

- **macOS：** 提示无法验证开发者时，到「系统设置 → 隐私与安全性」点「仍要打开」。
- **Windows（测试版）：** 蓝色提示窗口里点「更多信息」，再点「仍要运行」。Windows 版还没在真机上验证过，也没有微信提醒。

## 从源码运行

目前已在 macOS 上测试。Windows 还没有在真机上验证过，也没有微信提醒，欢迎试用并反馈。

需要 Node.js 22 或更新版本。安装和首次运行要下载 Electron，共占用约 400MB 硬盘。

```bash
git clone https://github.com/mi0668757-beep/wigglepet.git
cd wigglepet
npm install
npm start
```

在桌宠身上点右键，可以导入图片、修改动作、调整大小、开关活动和微信提醒、退出。在某个会动的部分上点右键，可以单独改它的动作。

## 选择会动的部分

右键选择「导入图片…」，选好图后可以点「自动识别并配动作」，也可以手动选：


1. 左键点要动的部分，右键点不要的部分。花纹多的角色要多点几个位置。
2. 范围不对时点「换个范围」，或继续加点修正。
3. 满意后点「设为会动的部分」，再选下一个，最多 12 个。这一步会自动精修边缘，每个约 1.5 秒。
4. 还有多余或缺失的地方，点旁边的「修」，用笔刷擦除或恢复。
5. 给每个部分选动作和跟随对象，点「完成，放到桌面」。

可选的动作：呼吸、摇摆、点头、探头、蹦跳、漂浮、抖动、爬（身体、先迈的手、后迈的手）、眨眼、单独眨眼、摇摇欲坠、不动。

想让角色更生动，可以把身体、眼睛和手分别选出来，眼睛和手跟随身体。选眼睛时，在脸颊和手上点右键，可以避免带上别的部分。

默认保留没选中的部分，取消勾选「保留没选中的部分」后，桌面上就只有选中的部分；自动识别后会自动取消勾选。

被选中的部分变成图层留在原位，底图和下层图层上被它盖住的位置会用周围的颜色补上，所以动起来不会有重影，闭眼时也不会露出第二双眼睛。动作幅度大时可能看到补过的地方，比如纸箱歪到最大时，下面的头发边缘会露出一点。

精修时会把选中的区域放大再分割一次，然后让边界贴合原图的颜色边缘，保留卡通描边并去掉边缘沾的背景色。结果会约束在预览范围附近，所以请先把预览点准。被挡住的部分补不回来。

## 自动识别（可选）

配置后，导入窗口里的「自动识别并配动作」按钮才可用。不配置也不影响手动选择。

默认使用阿里云百炼的 `qwen3-vl-plus`，也可以换成其他支持看图、兼容 OpenAI 接口的服务：

```bash
cp .env.example .env
```

然后在 `.env` 里填写 `QWEN_API_KEY`，`QWEN_WORKSPACE_ID` 可以不填。也可以直接在导入窗口里点「设置 API Key」填写，同样只保存在本机。`.env` 不会提交到仓库，Key 只留在主进程，页面读不回来。

- **隐私：** 点按钮时，图片会缩到最长边 1024 像素后上传给这家服务。分割和动画仍在本机运行。
- **费用：** 按服务商的计费标准由你自己承担。
- **结果可能不准：** 模型的判断和坐标都可能有偏差，结果里不合理的部分会被修正或丢弃，抠好后可以用笔刷修补，也可以手动换动作。
- **适合的图：** 色块分明的卡通图、剪贴画和 3D 渲染图效果最好。黑白线稿的小部件容易抠错，满幅带场景的插画没有可去的背景，不适合做桌宠。

### 分割模型

使用 [SlimSAM](https://huggingface.co/Xenova/slimsam-77-uniform)（Apache-2.0），在本机运行，图片不会上传。首次使用时自动下载约 38MB，之后可以离线使用。

如果下载不了，可以手动把这些文件放进项目目录：

```text
models/Xenova/slimsam-77-uniform/config.json
models/Xenova/slimsam-77-uniform/preprocessor_config.json
models/Xenova/slimsam-77-uniform/onnx/vision_encoder.onnx
models/Xenova/slimsam-77-uniform/onnx/prompt_encoder_mask_decoder.onnx
```

## 什么样的图效果最好

- 全身、站立、双脚分开，脚下能看到一条缝。
- 透明背景最稳；纯色背景时，角色最好有深色描边，否则和背景同色的部分可能被抠掉。
- 角色朝右。走路时图片只做水平翻转，朝左的角色看起来会倒着走。

自动识别只分析轮廓和像素，所以有这些限制：

- 选「不拆分，整张图一起动」时，贴在一起的对象分不开，复杂背景也去不掉。
- 分不出鱼和鸟这样的语义，自动动作只看形状，不对时请手动指定。
- 不配置自动识别时，动作需要手动指定。
- 图层只能整块动，尾巴、手臂这类局部要单独选中才能动，也不支持四足动物的腿部动作。

效果不好的图欢迎提 Issue。

## 微信提醒如何工作

它只通过 macOS 的 `lsappinfo` 读取系统记录的 Dock 角标数字：

```bash
lsappinfo info -only StatusLabel -app com.tencent.xinWeChat
```

- 不注入、不抓包、不调用微信协议，也不读取微信的数据文件。
- 只拿到未读数字，**看不到发送者和消息内容**。
- 开启时已有的未读只显示数字，只有数字增加才会提醒。

因此它有这些限制：

- 微信要在电脑上运行并已登录，还要在系统设置里允许微信显示图标标记。
- 每 3 秒检查一次，所以提醒最多可能晚 3 秒左右。
- 能否提醒完全取决于角标：数字不变就不会提醒，也无法区分是谁发来的。
- 暂不支持 Windows，欢迎贡献实现。

本项目与腾讯或微信没有任何关联。

## 到点提醒

默认 12:00 提醒吃午饭，18:30 提醒吃晚饭。饭后 40 分钟提醒喝水，之后每 1.5 小时一次，只在 9:00 到 21:00 之间提醒。电脑休眠错过饭点时，一小时内还会补提醒，超过就不再提醒。

右键菜单可以开关提醒、调整喝水间隔。想改饭点，可以编辑应用数据目录里的 `settings.json`：

```json
{
  "reminders": {
    "enabled": true,
    "waterMinutes": 90,
    "meals": [{ "id": "lunch", "time": "11:30", "lines": ["开饭啦～"] }]
  }
}
```

## 自己做一个宠物包

在 `pets/` 下新建文件夹，放入图片和 `pet.json`。`layers` 可选，坐标是图层在 `image` 里的位置，`parent` 是跟随的图层序号：

```json
{
  "name": "小占位",
  "image": "pet.png",
  "layers": [{ "image": "cat.png", "x": 120, "y": 40, "width": 80, "height": 60, "parent": null }],
  "lines": ["你好呀！", "喝口水吧"]
}
```

然后运行 `npm start -- --pet=文件夹名`。

请只使用你有权使用的图片。提交到本仓库的素材必须是原创或允许再分发的。

## 开发

```bash
npm test
```

| 文件 | 作用 |
|---|---|
| `main.js` | 桌宠窗口、活动范围、右键菜单、设置和导入 |
| `badge.js` | 读取 Dock 角标 |
| `vision.js` | 调用看图模型并校验结果 |
| `renderer/sprite.js` | 抠背景、拆对象、识别腿部、推荐动作（纯函数，有单元测试） |
| `renderer/pet.js` | 构图渲染、动作库和交互 |
| `renderer/editor.js` | 选择会动部分的窗口和分割模型调用 |
| `renderer/mask.js` | 清理分割结果、贴合边缘、补底图（纯函数，有单元测试） |
